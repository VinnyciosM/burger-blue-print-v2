# Imagens dos ingredientes

Coloque aqui as imagens dos ingredientes (png, jpg, webp, avif, svg ou gif).

**O nome do arquivo é o nome do ingrediente em minúsculas, sem acentos, com hífens no lugar dos espaços.**

| Ingrediente | Arquivo |
|---|---|
| Alface | `alface.png` |
| Alface e tomate | `alface-e-tomate.png` |
| Pão brioche base | `pao-brioche-base.png` |
| Hambúrguer smash | `hamburguer-smash.png` |

A lista completa de nomes está em `src/ingredientes.json` (campo `nome`).
Ingredientes sem arquivo aparecem normalmente, só que sem imagem.
Depois de adicionar arquivos, o servidor de desenvolvimento (`npm run dev`) já recarrega sozinho.
